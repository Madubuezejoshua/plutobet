# Archived implementation

This directory preserves the repository's pre-migration NestJS, Prisma,
BullMQ, Redis-worker, wallet, and odds code. It is intentionally excluded from
TypeScript and ESLint and is not part of the active Next.js/Drizzle/Inngest
application.

It remains here only as implementation history; do not add imports from active
modules into this tree or from this tree back into `src/`.
